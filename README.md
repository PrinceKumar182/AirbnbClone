# 🏡 Airbnb Listing Clone

A responsive, feature-packed Airbnb listing page clone built using **Next.js 15 (App Router)**, **TypeScript**, and **Tailwind CSS**. Designed with pixel-perfect UI precision, seamless interactions, and optimized performance.

📱 **[Live Demo](https://airbnb-clone-blond-kappa.vercel.app/)** | 📂 **[GitHub Repository](https://github.com/PrinceKumar182/AirbnbClone)**

---

## 📸 Key Features

- **Pixel-Perfect UI:** Closely mimics Airbnb's modern design system, typography, icons, and layout structure.
- **Interactive Image Gallery:** Grid view for featured listing photos with dynamic modal overlays for high-resolution viewing.
- **Dynamic Booking & Pricing Calculator:** Interactive guest selector, dynamic date/pricing calculations, and sticky checkout card UI.
- **Detailed Property Breakdown:** Amenities modal, host profiles, sleeping arrangements, and review/rating visualizations.
- **Fully Responsive Design:** Optimized for mobile, tablet, and desktop viewports with fluid layout adjustments.
- **Optimized Performance:** Server-Side Rendering (SSR) and Client Components balance powered by Next.js App Router for instant load times and dynamic SEO.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router, React 19 / TypeScript)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons & UI:** Lucide React / Custom SVG icons
- **Deployment:** [Vercel](https://vercel.com/)
